# Digital Politics and Electoral Behavior — Milei 2023

Reproducible analysis code for the MSc thesis *"Digital Politics and
Electoral Behavior: Social Media Communication and Electoral Support for
Javier Milei in Argentina's 2023 Presidential Election"* (Universidad
Carlos III de Madrid, MSc in Computational Social Science).

The thesis asks whether the emotional/rhetorical features of Milei's
digital communication (RQ1) correspond to the grievances that
distinguish his voters (RQ2): a pattern the thesis calls **strategic
alignment** (RQ3). RQ1 and RQ2 are independent analyses on independent
datasets; RQ3 compares their results, it does not model a causal link
between them.

## Execution order

Run everything with the **repository root as the working directory**.
R scripts must run **in the same R session**, in this order, for the
shared objects (`ranking_rq1`, `ranking_rq2`, etc.) to be available
where needed:

1. **`rq2_electoral_grievances/01_cnep_exploration.qmd`** (render with
   Quarto). Cleans the CNEP microdata, documents the undocumented
   missing code `90`, produces `data/processed/cnep_argentina2023_limpio.rds`.
2. **`rq1_digital_content/01_sentiment_classification.py`**. Runs the
   four pysentimiento classifiers (sentiment, emotion, irony, hate
   speech) plus the 9-category `context_hate_speech` model over the 450
   tweets; produces `data/processed/milei_tweets_con_sentimiento.csv`
   and Tables A.2, A.4, A.7, A.8, A.9.
3. **`rq1_digital_content/02_engagement_model.R`**. Negative Binomial
   engagement model; produces Tables A.3, A.5, A.6, and leaves
   `ranking_rq1`/`etiquetas_rq1` in the R session.
4. **`rq2_electoral_grievances/02_grievance_model.R`**. Three nested
   survey-weighted logistic models (H2/H3), plus the standardized
   grievance ranking among social-media users (for RQ3); produces
   Tables A.11–A.14, and leaves `ranking_rq2`/`etiquetas_rq2` in the
   session.
5. **`rq3_congruence/table1_and_appendix.R`**. Builds Table 1 (the
   6-dimension theory-guided comparison between RQ1 and RQ2) and prints
   a completeness check of `appendix_tables/`.

Steps 3–5 must run in the same R session (source each script, or run
them with `Rscript` chained in one shell session that keeps loading
`.RData`, or simply paste them into one interactive session in order).
Step 2 (Python) can run independently and only needs to finish before
step 3.

## Methodological notes worth knowing before reading the code

- **RQ1 standardizes with plain `scale()`**; **RQ2 standardizes with
  survey-weighted `svymean()`/`svyvar()`**. This is intentional, not an
  inconsistency: the 450-tweet corpus has no sampling design, while
  CNEP does. Using unweighted mean/SD on CNEP would bias the
  standardized coefficients toward the raw sample's composition instead
  of the population the survey design represents.
- The undocumented code `90` found in 17 CNEP variables is treated as
  missing (not a substantive response category), confirmed against the
  official CNEP v5.0 codebook. See `01_cnep_exploration.qmd`, Section 2.1.
- Models A/B/C in RQ2 share a common analytical sample (listwise
  deletion, N=1,421) so that AIC comparisons across models are not
  confounded by sample differences.
- Table 1's thematic grouping and per-row verdict (`RQ3 assessment`)
  are editorial decisions, defined by hand in
  `rq3_congruence/table1_and_appendix.R` (`definicion_tabla1`). Only
  the numbers (rank, standardized coefficient, p-value) are computed
  live from the fitted models.

## Known limitations (see thesis Discussion for full detail)

RQ1 and RQ2 do not share individuals. Table 1 evidences structural,
cross-domain correspondence between two independently observed
processes, not an individual-level causal effect of tweet exposure on
vote choice.
